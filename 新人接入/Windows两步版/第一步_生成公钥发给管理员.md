# 第一步：把公钥发给管理员

Windows 打开 PowerShell。已有专用密钥就不用重建；否则执行：

```powershell
New-Item -ItemType Directory -Force "$HOME\.ssh" | Out-Null; if (!(Test-Path "$HOME\.ssh\id_ed25519_sg_team")) { ssh-keygen -t ed25519 -f "$HOME\.ssh\id_ed25519_sg_team" -C sg-team }
```

再显示公钥和指纹：

```powershell
Get-Content "$HOME\.ssh\id_ed25519_sg_team.pub"; ssh-keygen -lf "$HOME\.ssh\id_ed25519_sg_team.pub"
```

把 `ssh-ed25519` 开头的完整公钥、`SHA256:` 指纹、姓名、英文用户名和系统发给管理员。**只发 `.pub` 公钥，不发送无扩展名的私钥，不发口令。**

管理员确认开通后，再做第二步。你已经提交过这把公钥，就跳过本步。
