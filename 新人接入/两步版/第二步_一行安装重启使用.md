# 第二步：交给本机 Agent 接入 · 团队中转

公开仓库中的 `203.0.113.10`、`relay.example.invalid` 及主机指纹均为示例。指纹来自 RFC8032 公开测试向量，绝不能用于真实部署。管理员须先将客户端、打包器和说明中的目标地址及固定公钥/指纹替换为自行核实的真实配置，再生成个人包。以下操作只适用于已完成配置的包。

管理员确认开通后，把**本人 Mac 个人包**交给可信的本机 Agent，发送：

> 请读取包内第二步全文，按附录完成已有安装检查、必要修复和 Codex App 验收。保留我的登录、历史和原配置，不输出密钥。需要我操作时只给一条明确命令，不要让我重新完整安装。

首次由 Agent 配置一次。日常在终端执行一行，再 **Cmd+Q 完整退出 Codex App，重新打开、新建对话**：

~~~bash
bash "$HOME/Codex团队接入/接入.command" team
~~~

这是示例团队入口，会检查或启动本套 SSH 后台连接。返回本人 ChatGPT 账号：

~~~bash
bash "$HOME/Codex团队接入/接入.command" personal
~~~

末尾改为 status 看配置模式，改为 usage 查本人用量，这两项不用重启 App。已登记本人第二中转时，用 other 切过去。original 兼容原入口，可能是第二中转，不一定是个人账号。

报错就把脱敏报错交回同一个 Agent，保留现场，不删除状态或重建密钥。个人包含本人 Key，不转发、不上传网页版 GPT。只停 SSH 不会恢复个人模式；旧对话不保证换线。

## 附录：本机 Agent 执行约定（必须读完再操作）

适用 macOS Codex **App**。App 内置后台自报 CLI 版本是正常的，不是要求改用 CLI。发布标识：2026-09-12-r2，模式 schema 3。这是队友接入版，不覆盖管理员已有 App 全局路由 wrapper。r2 仅新增 Windows 后台路径兼容处理，Mac 线路逻辑不变。

1. 核实当前用户、App 内置后台路径和版本、Python 3.11+、OpenSSH。读取本包个人参数.json 的非敏感身份，匹配本人已有公钥指纹及私钥路径，不重新生成。管理员未确认开通则停止。
2. 盘点 ~/.codex、~/.codex-sg-relay、已有接入目录。检查工作目录及祖先的 .codex/config.toml、App 启动参数和相关环境变量是否覆盖全局配置。只报告字段名、路径和冲突，不输出完整配置、Key 或认证文件。发现多份安装、profile、自定义 CODEX_HOME / CODEX_CLI_PATH 包装器则先审阅，不接管管理员专用路由。
3. 先备份实际配置和原接入程序，再把当前包放到 ~/Codex团队接入；旧解压目录改名保存。保留个人登录、历史、私钥、已有 token、原始快照和状态，不删除重置。已有成功修复版本须保留回退副本。
4. 执行准备命令：

~~~bash
bash "$HOME/Codex团队接入/接入.command" repair
~~~

此步用临时配置、本地模拟接口和虚拟 Key 检查 App 后台认证与 Responses 能力，不锁死旧 CLI 版本。隔离检查本身不调用真实模型；实际接入是否可用仍须后续验收。程序迁移完整旧状态或复用空状态，核验认证助手；不切 App 配置、不启动后台。成功只报“配置准备完成”。私钥口令由本人在本机输入，不移除口令。

5. 执行正文 team。它校验 SSH/API 就绪后切全局 sg_team，认证使用受管 helper，不把 Key 写入 TOML。操作前备份，事务失败回退本次已写文件；遇未知非空半安装、快照不匹配或并发配置修改立即停止。备份在 ~/.codex-sg-relay/备份，不上传；回退冲突须审阅，不继续覆盖。
6. 本套默认本地 127.0.0.1:18318 → 203.0.113.10:22 的 127.0.0.1:8317。固定公开主机密钥并校验指纹 SHA256:bbXpuKG6zhzdmnxq256TlqzFBzRl2f6OOg722cYNbU8。只用自己的 SSH 用户与私钥；不关闭主机校验，不请求服务器 shell。只管理本套后台，不抢未知端口，不添加开机自启，不碰其他隧道/VPN。
7. personal 明确选择内置 openai 与 ChatGPT 登录，保留原登录；账户地址覆盖则停止。other 仅登记并选择本人已有第二提供商，用 repair --other-provider 本人已有ID，不复制别人的配置、不管理第二隧道。非受管的模型偏好、项目、MCP/env 字段保留；只管理根路由选择和 sg_team，独立 canonical 可补回丢失的团队块。
8. 请用户保存任务并完整重启 App，以团队新对话验证；再切 personal、重启，以新对话确认本人账号和请求通道，最后恢复用户指定模式。不编辑任务 JSONL/SQLite，不承诺旧对话换线。尚未登录个人账号时让本人登录，此前记未验收。

每阶段简短回报。最终给 CONFIG_MODE、LOCAL_CAPABILITY、SSH_API、REPEAT_START、TEAM_APP、PERSONAL_APP、OTHER_APP、FINAL，各项标 PASS / BLOCKED / NOT_RUN / NOT_APPLICABLE，失败给首个阻塞点。重复 team 应复用自身后台，无端口冲突；CLI 或模拟成功不能代替 App 验收。已证明 API 可用时不重复耗额度生成。

新增 check 只恢复连接、不切配置。team 检测到 App 内核变化才重做本地模拟兼容检查；无关配置变化不再锁死。502/503/504 有限退避且不拆 SSH，401/403 停止。新格式自动事务保留最近 10 份，进程中断后下次运行恢复未完成事务；历史备份不动。这些动作由接入命令触发，不声称已经接管所有 App 启动或旧对话。

## 给网页版 GPT 的上下文

> 我用 Mac Codex App，通过示例团队的本人 SSH 隧道接入，也要保留个人账号切换。请按上传的两份说明一步步协助，先检查现有安装，不反复重装或重建密钥。每次只给一个必要操作，App 新对话实测前不宣布修好。我不会上传个人包、私钥、Key 或认证文件，请只索取脱敏输出。

只上传这两份说明和脱敏报错，保留同一网页对话。网页 GPT 无法直接操作本机，仍需本人执行核实后的命令。

用量中的 Cost 是参考价折算，不是 Pro 实际扣费或官方剩余额度；当前不设个人限额。
