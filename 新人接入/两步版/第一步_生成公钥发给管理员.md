# 第一步：生成公钥，发给管理员

团队中转 · 示例团队

Mac 打开“终端”，复制整行执行：

```bash
sg_key="$HOME/.ssh/id_ed25519_sg_team"; (umask 077; mkdir -p "$HOME/.ssh"; if [ ! -e "$sg_key" ] && [ ! -e "$sg_key.pub" ] && [ ! -L "$sg_key" ] && [ ! -L "$sg_key.pub" ]; then ssh-keygen -t ed25519 -f "$sg_key" -C sg-team || exit; fi; test -f "$sg_key" && test -f "$sg_key.pub" && ssh-keygen -lf "$sg_key.pub" && cat "$sg_key.pub")
```

首次会让你设置私钥口令并再输一次；只在自己电脑上输入。已有同名文件不会覆盖。报错就把报错发管理员，不删旧密钥。

把最后显示的 **`ssh-ed25519` 开头整行**复制给管理员，同时告诉他：你的姓名、电脑系统，以及希望用的英文用户名。`SHA256:` 那行也一起发。

只发公钥。不要发不带 `.pub` 的私钥文件、口令或整个 `.ssh` 文件夹。等管理员发给你“个人开通包”，再做第二步。

Windows 用户：打开 PowerShell，执行下面这一整行；生成后发送的内容相同。

```powershell
$sgKey = Join-Path $env:USERPROFILE '.ssh\id_ed25519_sg_team'; New-Item -ItemType Directory -Force (Split-Path $sgKey) | Out-Null; if (!(Test-Path $sgKey) -and !(Test-Path "$sgKey.pub")) { ssh-keygen -t ed25519 -f $sgKey -C sg-team; if ($LASTEXITCODE -ne 0) { throw '生成失败，请联系管理员' } }; if (!(Test-Path $sgKey -PathType Leaf) -or !(Test-Path "$sgKey.pub" -PathType Leaf)) { throw '密钥文件不完整，请联系管理员' }; ssh-keygen -lf "$sgKey.pub"; if ($LASTEXITCODE -ne 0) { throw '公钥校验失败' }; Get-Content "$sgKey.pub"
```

Mac 使用本目录第二步；Windows 使用 Windows两步版，须由管理员提供相应个人包并在本人电脑验收，不要运行 Mac 命令。
