# Mac 团队中转 · 交给本机 Codex Agent

这是绑定本人 SSH 公钥的团队个人包。不要上传、转发或打印其中的成员访问密钥。私钥留在本机；需要口令时只由用户在本机输入。预算是本服务内每位成员最多 100 美元，不是个人 ChatGPT 账户余额。

从解压后的个人包目录执行：

1. 使用 `bash 接入.command prepare` 验证身份、保存原配置。若私钥不是 `~/.ssh/id_ed25519_sg_team`，在 `prepare` 后传 `--ssh-key 本人私钥路径`。不要重建或复制私钥。发现自定义 Codex 目录或配置有冲突时停止，交给用户决定。
2. 得到管理员确认后，使用 `bash 接入.command team` 建立固定服务器 SSH 隧道，核对限额网关返回的模型，再切团队线路。保存任务，完整退出并重开 Codex App，使用**新对话**；旧线程不会被改写。
3. 使用 `bash 接入.command status` 核对配置和隧道。不把状态输出当成真实 App 请求证明。模拟环境只能发模拟请求；付费环境按管理员许可发一次短请求，失败停止，不反复尝试。
4. 使用 `bash 接入.command personal` 切回并重启 App。不再使用团队线路时，可以 `bash 接入.command stop` 停止本包的隧道。个人登录、OAuth、历史和系统网络设置不属于本包管理范围。

首发仅支持固定模型的文本、流式回复及客户端本地工具；团队模式暂不启用外部 MCP、网页搜索和多代理。切回原配置会恢复它们。额度不足在服务器本地拒绝；首发不承诺图片、文件或自动压缩。
